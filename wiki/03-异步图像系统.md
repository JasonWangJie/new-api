本页汇总 2026-09-17 的异步图像相关提交：`c211e365`、`f10ffe5d`、`6e9a9c31`、`f5c05a1d` 和 `75e4f734`。

## 功能组成

### 异步图像 API

公开接口位于 `/v1`，支持异步生成、编辑、任务查询和输入上传：

- `POST /v1/images/generations_async`
- `POST /v1/images/edits_async`
- `POST /v1/images/generations_oa`
- `POST /v1/images/edits_oa`
- `POST /v1/chat/completions_gm`
- `POST /v1/images/generations_sc`
- `POST /v1/uploads/images_sc`
- `GET /v1/images/tasks_async/:task_id`
- `GET /v1/tasks_sc/:task_id`

请求经过 Token 验证、Token 图像平台权限、协议识别、能力校验、渠道路由、计费预处理和异步任务持久化。任务 worker 使用租约避免多个实例重复处理，并记录重试、失败和结算状态。

#### 队列与上游轮询

- 新任务在数据库中与 event/outbox 同事务落库，outbox dispatcher 以 1 秒节拍投递可执行命令；正常空闲时不再等待默认 30 秒恢复扫描。
- `queued` 仅表示尚未被 worker 抢占或容量闸门已满。worker 抢占且选定渠道后对外显示“处理中”。
- Alibaba、Replicate 等先返回上游任务 ID 的渠道，在上游已接单后持续显示“处理中”。每次查询完成后释放数据库执行租约，按任务的 `next_attempt_at` 再投递，不会被默认 120 秒租约挡住。
- Redis 队列仍然是可重建的投递层；周期恢复扫描保留，用于 Redis 数据丢失、进程中断或临时连接失败后的收敛。

### 图像工作台

入口：`/image-workbench`

- 根据当前用户和 Token 加载可用平台、模型、尺寸、质量、数量和参考图能力。
- 支持多种图像请求格式和本地参考图处理。
- 提交后显示异步状态和结果，并可进入任务中心继续跟踪。
- 工作台将图像/视频切换栏与内容区组成受视口约束的纵向布局；选择 `gpt-image-2` 等带额外能力参数的模型后，表单在剩余高度内滚动，所有动态参数和生成按钮都可达。
- Token 编辑界面可以配置图像平台分组，限制 Token 可使用的平台。

### 任务中心

用户入口：`/async-image-tasks`

管理员入口：`/admin/async-image-tasks`

- 支持分页、筛选、任务详情、输入参数、结果图像、耗时和成功率展示。
- 管理员可恢复或终止任务，并支持批量终止。
- 状态、平台和请求类型使用统一徽章与视觉映射。
- 自动刷新默认关闭，用户可按需开启。
- 任务详情采用预取；结果对象 URL 按需异步获取。

### 图像对象和签名 URL

- 图像结果保存为对象记录，业务数据保存对象标识和元数据，不在列表查询中直接加载大文件。
- 结果访问生成带过期时间的签名 URL，避免把永久存储地址直接暴露给客户端。
- 用户只能访问自己的任务结果；管理员查看需要对应权限。
- 后台清理任务负责临时对象、失败残留和过期数据。

### 个人图库

入口：`/image-library`

- 支持导入本地内容、远程 URL 和任务结果。
- 支持查看、修改、删除、发布和撤回作品。
- 发布可以直接提交，也可以创建延迟提交请求并同步处理状态。

### 图像广场和内容审核

用户入口：`/image-plaza`

管理员入口：`/admin/image-moderation`

- 广场展示已通过审核的公开作品。
- 用户可以提交作品、撤回发布和举报内容。
- 管理员可以审核发布申请、批量处理作品、查看举报并标记处理结果。
- 管理员可以查看图库统计、迁移状态和清理任务。

## 配置与权限

图像配置接口位于 `/api/option/images`，包含运行参数、渠道池、策略和存储配置。

平台策略页会根据当前选择的平台展示模型能力 JSON 示例入口。弹窗中的模板覆盖 OpenAI、Gemini、Vertex AI 及其他已注册图片供应商；动态注册且没有内置模板的平台使用带平台名的占位模型。Gemini 原生模型示例固定 `max_output_images` 为 `1`，Imagen 示例固定 `max_reference_images` 为 `0`。管理员应把模型 ID、可选能力和数量限制调整为渠道实际上游支持的值，再一键复制到“模型能力”输入框；示例只用于参考，不会自动覆盖当前表单。

相关权限包括：

- 异步图像任务读取和管理。
- 图像内容审核读取和管理。
- 图像配置读取和管理。

前端为新增功能补齐 en、zh、zh-TW、fr、ja、ru、vi 七种语言。
