# 站内文档中心

本页说明公开文档模块 `/docs`：顶部「文档」入口改为站内页面，内容参考 JuAPI 快速开始文档结构，并将原 `hejuapi.com` 地址替换为 `https://api.aiimg.lol/`。

## 入口行为

- 顶部导航「文档」固定跳转到 `/docs/`，不再跟随后端 `docs_link` 打开外部站点。
- `/docs/` 与 `/docs/quickstart/` 会重定向到默认文档页 `/docs/quickstart/tokenrouter`。
- 首页 Hero 中的「文档」按钮同样指向站内 `/docs/`。

## 页面结构

- 左侧为分组导航（快速开始、环境准备、控制台、Claude Code、Codex、IDE 与 Agent、FAQ、Skills、AI 创作指南等）。
- 中间为文档正文，支持标题、段落、列表、步骤、提示框、代码块、表格、折叠项和文档卡片等块类型。
- 右侧为当前页目录（宽屏）；窄屏通过「目录」按钮打开侧栏。
- 文内 `https://www.hejuapi.com` / `https://hejuapi.com` 已全部替换为 `https://api.aiimg.lol`。

## 内容来源与维护

- 静态内容包：`web/src/features/docs/data/quickstart.zh.json`。
- 可用脚本 `scripts/fetch-hejuapi-docs.py` 重新拉取并替换域名后写入上述文件。
- 当前仅内置 `quickstart` 空间的中文文档；其他空间若后续补充，可按相同数据结构扩展。

## 验证

- `docs-catalog` 测试确认默认路径、邻居页和 `api.aiimg.lol` 替换。
- `docs-hub` 测试确认正文渲染与移动端目录交互。

## 公开异步生图 API 文档

- 新入口：顶部「异步生图API文档」，地址 `/async-image-api-docs`。未登录也可直接打开，没有登录跳转、API Token 或账户权限要求。
- 菜单与既有「文档」入口一起受顶部文档开关控制；隐藏菜单不限制该公开地址的直接访问。
- 独立公开内容为 `web/src/features/docs/data/async-image-api.zh.md`，公开页面不直接导入根目录文档。异步生图接口每次变更须同步维护此正文、根目录 `异步生图API接口文档.md`、`异步生图API接口文档-用户版.md` 和 `/guide/async-image-api`，保持参数、默认值、边界、示例和错误说明一致；具体强制要求见根目录 `AGENTS.md`。
- 公开副本去掉仓库地址、仓库路径、管理员照填手册和配置文档链接；保留 new-api / QuantumNous 项目署名、图片/视频调用流程、响应示例及错误说明。页面仅保留文内章节链接，其他链接显示为普通文字，避免后续维护时意外展示外链。
- 复用 `PublicLayout`、`RichContent` 和共享 `Markdown`，支持表格、代码块、暗色主题和章节锚点；没有引入另一套文档渲染器。原 `DocsHub` 和控制台 `AsyncImageGuide` 分别面向结构化文档中心、登录后的简要指南，继续保留原用途。
- 顶部导航固定宽度与 64px 高度，滚动仅改变背景，不再横向移位或缩成窄条。1280px 起显示不压缩、不省略的横向菜单；更窄屏幕使用原有展开菜单，支持滚动、可访问名称和展开状态。控制台也恢复既有小屏下拉菜单的可见性。
- 菜单标签已补齐 en、zh、zh-TW、fr、ja、ru、vi；中文正文单独标记 `zh-CN`，不会因切换界面语言而误称已翻译全文。
- Rsbuild 将 `.md` 纳入资源类型并按路由加载；Docker 上下文只额外允许该公开副本，不需要复制根目录原文。

本次仅本地代码、公开副本和验证，未上线或重启服务。精确范围与验证记录见[10 月台账](10-2026年10月代码变更台账.md#public-async-image-api-docs-change)。

### 2026-11-06：GIF 与 SVG 参数同步

两份根目录接口文档与上述两个页面同步增加 `gpt-image-2.6-flare`、`gpt-image-2.6-sunburst` 的 `output_format`（默认 `png`，另支持 `webp`、`jpeg`、`gif`、`svg`），以及仅 GIF 可用的 `frame_count`（默认 9，2–16）和 `frame_duration_ms`（默认 200，20–2000 毫秒）。公开正文保留原有展示边界，登录指南继续使用现有参数表与可复制示例。实现及本地验证见 [11 月台账](14-2026年11月代码变更台账.md#async-image-gif-svg-20261106)；未发布。

### 2026-11-06：统一场景示例与接口契约整理

- 根目录两份 API 文档、公开正文与登录指南同步按现有代码整理。调用示例只传模型与业务参数，不传 `provider`，删除按供应商和渠道展开的重复示例；后台既有兼容参数解析不变。
- 图片示例为文生图、图生图；视频示例为文生视频、参考素材生视频、首尾帧生成、视频编辑、视频延长。使用待替换的模型名占位符，并就近说明素材字段、时长、比例与文件上传方式受模型能力限制，不能将一个示例推广为所有模型通用。
- 本次新增 GIF、SVG、`frame_count`、`frame_duration_ms` 仅适用于 OpenAI 2.6+ 生图系列；当前明确适配两款 2.6 型号。帧参数默认值、范围、错误条件及上游实际帧控制限制在四处保持一致。
- 按实现修正结果文件路径、回退与过期状态、同 Key 查询和账户级统计的区别。公开正文继续不展示仓库或管理员配置链接；指南复用既有章节与复制控件，不新增通用组件。
- `AGENTS.md` 固定按场景组织示例、请求不传 `provider` 和模型专属能力就近标注的规则。日期、提交状态及验证见 [11 月台账](14-2026年11月代码变更台账.md#async-media-unified-examples-20261106)；本地整理，未发布。
