# 异步视频与统一媒体任务

本页记录提交 `6f340ebe16abfeafec10e5d20dfa11dad1e7b2c4` 引入的异步视频和统一媒体能力。完整提交清单见 [2026 年 9 月变更记录](02-2026年09月代码变更台账.md)。

## 用户流程

图像工作台中的视频工作区支持提交异步视频任务。提交后页面保存任务 ID，轮询统一媒体查询接口，并在任务完成后展示可访问的视频结果。

任务中心统一展示图像和视频任务。用户可以查看任务详情、恢复可恢复任务，或终止仍在处理的任务。管理员使用相同的数据结构查看全站任务，并通过已有异步任务管理权限执行操作。

## 公共 API

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/v1/videos/generations_async` | 提交异步视频生成任务 |
| `GET` | `/v1/media/tasks_async/:task_id` | 查询统一媒体任务状态和结果 |
| `GET` / `HEAD` | `/v1/media/objects/:object_id` | 通过签名链接读取媒体对象 |

创建任务沿用 API Token 鉴权、渠道筛选和分发逻辑。接口接收任务后返回任务标识，由后台 worker 完成上游提交、状态轮询、结果下载、对象归档和计费结算。

## 用户与管理接口

用户接口：

- `GET /api/user/media-tasks`
- `GET /api/user/media-tasks/:task_id`
- `POST /api/user/media-tasks/:task_id/resume`
- `POST /api/user/media-tasks/:task_id/terminate`

管理端提供对应的 `/api/admin/media-tasks` 查询、详情、恢复和终止接口，并接入现有异步任务管理权限。

## 数据和后台处理

- `async_media_jobs` 保存统一媒体任务、上游任务标识、计费状态、错误信息、租约和重试数据。
- 媒体对象记录保存对象归属、存储位置、内容类型、大小、过期时间及访问所需信息。
- worker 使用租约避免多个实例重复处理同一任务，并按配置执行轮询、下载和失败重试。
- 本地媒体存储使用临时文件和原子替换，避免未写完的对象被读取。
- 结果链接采用签名和过期时间控制；后台清理任务按保留期删除过期对象。

## 配置

媒体设置并入图像设置页面，包含：

- 是否启用异步视频。
- 本地媒体存储目录。
- 媒体保留天数。
- 签名链接有效期。
- 单个媒体对象最大字节数。
- 下载超时、并发数和重试次数。

默认本地目录为 `data/media`，默认保留 90 天，签名链接默认有效 3600 秒，单个对象默认上限为 1 GiB，下载默认超时 900 秒、并发数 2、重试次数 5。管理员修改配置后，新的后台处理流程使用最新配置。

## 渠道和插件

统一媒体任务通过能力描述判断渠道是否支持异步视频及对应动作。相关适配器负责生成上游请求、解析任务标识、查询进度和标准化结果。提交同时扩展了阿里云、Google、Vertex 等任务插件，并复用 Replicate 等现有异步任务链路。

## 前端和验证

- `VideoWorkbench` 和 `VideoResults` 集成在图像工作台中。
- 任务中心和详情页统一展示图像、视频、进度、结果及失败信息。
- 设置页通过 `/api/option/images/media` 读取和保存媒体配置；保存成功后立即显示明确反馈，并刷新服务端配置。
- 图像设置中的共享渠道池按媒体平台联动显示可执行模型和已启用渠道；视频任务插件平台同样按插件声明的协议与兼容渠道类型过滤，编辑已有绑定时会自动回填原模型、渠道和优先级。
- 新增界面文案已同步到七种前端语言。
- 后端覆盖任务创建、状态流转、租约、签名对象访问、清理和多数据库行为；前端覆盖工作台、结果展示和任务详情。
