## 功能概览

### 异步图像、图库与图像广场

- 新增兼容多种图像请求格式的异步提交与查询接口。
- 新增图像工作台、用户及管理员任务中心、任务详情和结果展示。
- 新增图像对象存储、签名 URL、清理、失败处理、渠道路由和计费衔接。
- 新增个人图库、图像广场、发布申请、举报、内容审核及管理员清理能力。
- 新增 Token 图像平台分组配置、图像运行配置、存储配置和权限资源。

### 首页改版与部署工具

- 公开首页切换为 Cyber Landing，加入模型网络视觉、能力介绍、API 引导、动态控制和登录状态感知入口。
- 新增适用于 Fork 部署的 Docker Compose、首次安装、离线导出、备份、更新、恢复和运行管理脚本。
- 部署栈使用 PostgreSQL、Redis、健康检查、日志轮转和本地数据目录。

### 异步视频与统一媒体任务

- 新增异步视频提交、查询、重试、终止和管理员管理接口。
- 新增统一媒体任务模型、租约式 worker、本地媒体存储、签名下载和定期清理。
- 图像工作台加入视频工作区，任务中心统一展示图像和视频结果。
- 扩展渠道能力、任务插件和前端媒体运行设置。

### 企业开票申请与历史补开

- 用户可在 `/wallet/invoices` 跨页选择人民币易支付充值订单，填写企业名称、企业税号和接收邮箱后提交申请。
- 用户可查看申请状态、关联订单、开票金额、处理时间和拒绝原因；申请被拒绝后，相关订单可以再次申请。
- 管理员可在 `/admin/invoices` 完成或拒绝申请，也可按用户搜索历史订单并补录已经线下开具的发票。
- 超级管理员可配置用户申请开关和最低开票金额。
- 当前交付是申请及人工处理台账；自动开票、附件上传和自动邮件发送不在本期范围内。

## 文档维护规则

1. 每次新增、移除或修改功能时，同一变更必须更新本文件中的功能索引或变更记录。
2. 同一变更必须同步更新 `wiki/` 下对应的详细页面；没有对应页面时应新增页面并加入 `wiki/01-首页.md`。
3. `wiki/` 目录下的 Markdown 文件必须使用“二位序号 + 连字符 + 中文名称”的格式，例如 `07-功能名称.md`；新增、重命名或删除页面时必须同步更新全部引用和目录页。
4. 每个 Git 提交应在对应月份的 Wiki 代码变更台账中保留提交时间、提交哈希、变更范围和实际行为摘要。
5. 不修改原有 `README*.md`、`docs/` 或其他既有说明文件，除非用户明确指定要修改其中某个文件。
6. 文档必须描述最终实际行为、权限、配置、接口、数据迁移、验证结果和仍存在的限制，不能记录已放弃的实现方案。
7. 功能代码、测试和文档应在同一提交或拉取请求中保持一致。
